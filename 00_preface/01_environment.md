# Environment

This file contains the necessary setups for building, running and testing examples in this repo.

They are shell environments, so it can be eaisly modified on your demand.

```bash
export LDD_ROOT=/path/to/dir/hosting/the/repo
export KERNEL_VERSION=6.12.21
export QEMU_VERSION=9.2.3
export PATH="$PATH:$LDD_ROOT:/bin"
```
